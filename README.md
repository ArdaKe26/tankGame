This is a project I am making to sharpen my skills with unity and to learn new skills which I will be using for my next game plans.
This game is about tanks and fighting. There are 4 tank types to choose from. There also are a lot of different powerups that you can get. The Game can be played with 1 player or 2 player. There also is an AI system integrated in the game to control the tanks that user does not use. Shooting mechanism is that the longer you press spacebar the stronger your bullet is going to be.
